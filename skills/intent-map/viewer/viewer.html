Intent Maps

Every intent map (goal, needs, solutions, tests, each solution with its status) lives in this page's store and renders here live. Pick a map on the left, or open the overview to see how the maps connect: solid arrows are explicit references between maps, dashed lines are suggestions computed from the terms two maps share.

How maps get here

Maps are written as one s-expression file each and pushed from code, so adding or editing a map costs no tokens in the page and needs no republish:

python3 skills/intent-map/scripts/intentmap.py NAME.sexpr --no-png --store <this page's URL>

The file name (without .sexpr) becomes the map's slug and its address here (#slug). An optional (project "name") groups it in the list; (ref other-slug "why") links it to another map. Pushing the same file again updates the map. Each map is one doc in the maps collection.
